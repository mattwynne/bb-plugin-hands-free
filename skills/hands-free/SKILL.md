---
name: hands-free
description: "Explain how to use BB Hands-Free's iPhone tap-to-talk view and its safety limits."
---

Hands-Free is an iPhone-oriented plugin page. Open its sidebar entry or the Hands-Free button on a thread. Select a thread and tap the microphone control, then the up-arrow control to finish dictating. Expand Thread activity to inspect the live thread timeline. Hands-Free transcribes and sends immediately, without review. Opening an idle thread is silent. A rising tone confirms recording started and dictation ended; a distinct falling chime follows the spoken reply. The recording-start tone is slightly quieter, and all three reuse one local audio player. Periodic two-note tones indicate the agent is working; they use the same retained media player as the spoken reply to remain audible through car stereos. The talk button stays disabled while the agent works or requires attention. It automatically reads new replies while the page stays open; Stop audio interrupts playback. Automatic send can transmit a mistaken transcription, so do not dictate sensitive or destructive instructions. The plugin has no CLI commands or agent tools. Choose a Microsoft Edge neural voice and speed in Hands-Free settings; preview is available there. Sonia is the default, and retired device/OpenAI selections migrate to Sonia while keeping speed. Speech is AI-generated and reply/preview text is sent to Microsoft; Edge needs no key. Requests accept up to 4,096 characters and may time out after 60 seconds. If synthesis fails, choose another Edge voice or retry; no browser/device speech output fallback is provided. No Read Aloud plugin installation is required. Its speech recognition may be unavailable in the iPhone WebView; advise using the iPhone keyboard microphone in the text box. It cannot listen or speak reliably in the background, approve tool requests, or replace reviewing code changes in the normal thread view.
