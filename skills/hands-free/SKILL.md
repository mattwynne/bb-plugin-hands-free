---
name: hands-free
description: "Explain how to use BB Hands-Free's iPhone tap-to-talk view and its safety limits."
---

Hands-Free is an iPhone-oriented plugin page. Open its sidebar entry or the Hands-Free button on a thread. Select a thread and tap Tap to talk, then Finish dictating. Hands-Free transcribes and sends immediately, without review. Opening an idle thread is silent. A rising tone confirms recording started and dictation ended; a distinct falling chime follows the spoken reply. The recording-start tone is slightly quieter, and all three reuse one local audio player. Quiet periodic notes indicate the agent is working. The talk button stays disabled while the agent works or requires attention. It automatically reads new replies while the page stays open; Stop audio interrupts playback. Automatic send can transmit a mistaken transcription, so do not dictate sensitive or destructive instructions. The plugin has no CLI commands, settings, or agent tools. Its speech recognition may be unavailable in the iPhone WebView; advise using the iPhone keyboard microphone in the text box. It cannot listen or speak reliably in the background, approve tool requests, or replace reviewing code changes in the normal thread view.
