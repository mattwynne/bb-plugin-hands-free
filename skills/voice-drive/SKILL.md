name: voice-drive
description: "Explain how to use BB Voice Drive's iPhone tap-to-talk view and its safety limits."
---

Voice Drive is an iPhone-oriented plugin page. Open its sidebar entry or the Voice button on a thread. Select a thread, tap Tap to talk, review the transcript, then explicitly tap Send this reply. Read reply speaks the latest answer; automatic read is opt-in while the page is open. The plugin has no CLI commands, settings, or agent tools. Its speech recognition may be unavailable in the iPhone WebView; advise using the iPhone keyboard microphone in the text box. It is not CarPlay and cannot listen or speak reliably in the background. Never claim it can approve tool requests or safely supervise code changes while driving.
