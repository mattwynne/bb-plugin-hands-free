name: voice-drive
description: "Explain how to use BB Voice Drive's iPhone tap-to-talk view and its safety limits."
---

Voice Drive is an iPhone-oriented plugin page. Open its sidebar entry or the Voice button on a thread. Select a thread and tap Tap to talk, then Finish dictating. Voice Drive transcribes and sends immediately, without review. A rising tone signals ready/recording, a descending tone confirms dictation ended, and quiet periodic notes indicate the agent is working. The talk button stays disabled while the agent works or requires attention. It automatically reads new replies while the page stays open; Stop audio interrupts playback. Automatic send can transmit a mistaken transcription, so do not dictate sensitive or destructive instructions. The plugin has no CLI commands, settings, or agent tools. Its speech recognition may be unavailable in the iPhone WebView; advise using the iPhone keyboard microphone in the text box. It is not CarPlay and cannot listen or speak reliably in the background. Never claim it can approve tool requests or safely supervise code changes while driving.
